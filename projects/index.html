Projects

Some of the things I've built that I'm proud of.

  • PhpStorm Light An experimental, trimmed-down PhpStorm build: faster startup, lower memory, fewer bundled features.
  • php-debugger A lightweight PHP debugger extension, forked from Xdebug and stripped down to debugging only.
  • DAWhub Diff and version control for FL Studio projects. Starting with a CLI for tracking what changed.
  • The PHP Foundation The non-profit that funds PHP core development. I founded it in 2021 and led it as its first Executive Director until 2026.
  • MCP PHP SDK The official PHP SDK for the Model Context Protocol, built by Symfony and The PHP Foundation. I initiated it with Anthropic and coordinated it through the Foundation.
  • PHP Digest A Russian-language PHP newsletter I started in 2012: 222 issues on Habr, now a monthly Telegram channel. PHP Annotated grew out of it.
  • redpen A macOS menu-bar app that critiques your English instead of correcting it.
  • redditify Render Reddit threads on your own website.
  • php-src-developer A Claude Code plugin for working on the PHP language core, php/php-src.
  • PHP Typehints Extra A PhpStorm plugin that adds extra type-hinting capabilities to PHP code.
  • Elephpant Progress Bar A PhpStorm plugin that replaces the progress bar with an elephpant.
  • PHP 8.0 release page The php.net page that announced PHP 8.0. I proposed it, designed it with Alexander Makarov and Svetlana Belozerova, and shipped it; the template served every release through 8.4.
  • 25 Years of PHP A timeline of PHP's history for the language's 25th birthday in 2020, with the data open-sourced and reviewed by core contributors.
  • mcp Archived The fast, PHP way to build MCP servers: tools, resources and prompts in plain PHP.
  • phpup Archived A single-file PHP toolchain: Composer and other tools without PHP installed on the machine.
  • Search Exclude Acquired by QuadLayers in 2023 A WordPress plugin that hides chosen pages and posts from search results.
